## Метод и его границы

Восемь агентов-аналитиков прошли по репозиториям с требованием указывать путь к файлу для каждого утверждения; отдельно различались «реализовано в коде», «запланировано в документах» и «объявлено бесплатным по дизайну». Пять агентов-сканеров искали дублирование по направлениям: идентичность и доступ; лиды, согласия, антифрод; AI-слой; брони и доставка; токены, события, локали, SEO.

**Проверочный проход выполнен не полностью.** Независимая верификация прошла для Other Bali, Petid.care и DOKI. Для ArchiDom, KORA, 2MoonSpa, Villa Ops, Selena Systems и **всех пяти сканов дублирования** верификаторы упали по лимиту доступа. Пути к файлам собирались с проверкой существования, но выбор «канонической» реализации — суждение агента. Перед извлечением каждого общего пакета донора нужно просмотреть глазами.

## Три вывода в одном абзаце

Ни один продукт не принимает деньги — платёжный код есть только у KORA, но без prod-ключей. Ядро платформы уже написано внутри Petid.care (14 из 32 канонических механизмов) и DOKI (7), поэтому нужен не проект «построить платформу», а извлечение пакетов из этих двух. Из 24 блокеров только 5 требуют кода: инженерия опережает операционку примерно на квартал, а ближайший жёсткий срок — 1 сентября, когда одновременно открываются KORA Test Delivery и 2MoonSpa.
